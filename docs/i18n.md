# Internazionalizzazione

**43 lingue**: tutte le 24 lingue ufficiali UE, 14 altre lingue europee (be, bs, ca, cy, eu, gl, is, lb, mk, no, sq, sr, tr, uk), più russo, cinese (semplificato), arabo (RTL), giapponese e coreano.

- Rilevamento: lingua salvata → `navigator.languages` (con alias `nb`/`nn` → `no`) → inglese.
- Cambio lingua dal pulsante globo; tutta la UI si ridisegna senza ricaricare.
- RTL: `document.documentElement.dir = 'rtl'`; layout con proprietà logiche (`inset-inline-start`, `text-align: start`); le griglie di gioco restano `dir="ltr"`.
- Fallback: chiave mancante → inglese → nome della chiave (la CI blocca prima).

Procedura dettagliata: `.claude/skills/i18n/SKILL.md`. Verifica: `node tools/i18n-check.mjs`.
